# Authenticity catalogue — is this document what it claims to be?

Run these during the every-page read (Step 4) and the cross-document pass (Step 8). Every failed check becomes a `checks[]` entry with `result: "flag"` on the document, and material ones also become a `red_flags[]` entry using the `check` keys below. A signal is a lead, not proof: state it once, weigh it against the rest of the file, and recommend a verification step instead of an accusation.

## 1. Metadata weighting (from `pdf_forensics.py` output)

The script reports facts; weight them by document type:

| Producer/creator class | Payslip, bank statement, NOA, credit report, contract | ID document (photo of a card) | Broker-authored (notes, letters) |
|---|---|---|---|
| Payroll / bank / ATO / CRM / e-sign system | expected → pass | n/a | n/a |
| Browser save (Skia, Chrome), scanner, Quartz/Preview, print-to-PDF | normal → pass (client downloaded or scanned it) | normal → pass | normal |
| **Word / Photoshop / Canva / online PDF editors** | **high flag** (`pdf_tamper`) - these documents are generated by systems, never authored in an editor | routine - clients paste card photos into Word. Info only; the photo itself gets the visual pass | fine |

Other signals, any doc type:
- `mod_date` after `creation_date`, or after the document's own printed date → medium; downgrade to info when the producer is a benign re-saver (scanner, mail gateway) and nothing else flags.
- `eof_count > 1` (incremental saves) → info alone; medium when paired with an editor producer or a failed arithmetic check.
- `touchup_textedit` → high, always (`pdf_tamper`): text was edited in place after creation.
- Annotation overlays (FreeText/Ink/Stamp) sitting on top of figures → medium (`doc_altered`): numbers may be covered by typed boxes.
- Metadata unavailable (image, encrypted, odd structure) → `result: "unavailable"`, never a flag by itself; say coverage was reduced.

## 2. Payslip internals (`payslip_arithmetic`, high when out)

Every payslip must reconcile. Show your working in the check detail:
- rate × hours = period gross (allowing for loadings, penalties, allowances shown)
- gross − tax − pre-tax deductions − post-tax deductions = net
- YTD gross − YTD tax − YTD deductions = YTD net
- super ≈ 12% × ordinary time earnings (SG rate from 1 July 2025; a big shortfall on a legit slip is itself worth a note)
- PAYG withholding plausible for the annualised gross - a round-hundreds tax figure on a precise gross is a classic fabrication tell (`paygw_implausible`)
- HECS/HELP: if withholding sits well above standard tax + 2% Medicare, expect a HECS component; note it for policy

**YTD progression (`ytd_progression`, high):** across payslips for the same employer, YTD must step by exactly the period amounts, in date order. An earlier payslip showing a HIGHER YTD than a later one is fabrication until explained. YTD start date must match the pay frequency and the financial year.

**Employer ABN (`abn_invalid`, high):** validate every ABN with `pdf_forensics.py --abn "<abn>"`. An invalid check digit on a payslip is a serious tell. Missing ABN entirely → part of the fraud score.

**Payslip fraud score 0-10** (sum, cap 10; record per payslip):
round-number net (+2) · no employer ABN (+2) · no YTD figures (+2) · generic template look, e.g. mismatched fonts or an online paystub layout (+2) · net pay not found in bank credits (+2) · editor producer (+2) · arithmetic failure (+3).
0-2 clean · 3-5 verdict review · 6+ verdict fail.

## 3. Bank statement internals (`balance_continuity`, high when broken)

- Where printed: opening balance + total credits − total debits = closing balance.
- Page chain: last running balance on page N = first on page N+1. A jump means pages were removed or figures altered.
- Transaction dates in order, no gaps that don't match the period.
- Rounded-dollar salary credits, or salary credits that stop mid-period, get a note.

## 4. Cross-document ties

- **`salary_credit_mismatch` (high):** each payslip's net pay must appear as bank credits of matching amount and cadence. Payslips on file with NO matching salary credits anywhere is one of the strongest fraud tells there is.
- **`employer_mismatch` (medium):** employer name and ABN consistent across payslips, employment letters and the statement credit descriptions (banks truncate - match sensibly).
- **`name_mismatch` / `dob_mismatch` (high):** name and DOB consistent across every document, fuzzy-matched with the Step 5 gate. Spelling drift between the contract, the IDs and the payslips gets called out.
- **NOA vs payslips (medium):** taxable income on the NOA consistent with that year's YTD evidence for the same person.
- **Address:** where shown, consistent; the checklist requires at least one ID with the current residential address.

## 5. Visual and textual tells (`visual_inconsistency`, `spelling_grammar`)

While reading each page:
- Mixed fonts, weights or sizes within one line or one column of figures
- Misaligned columns or decimal points; figures that don't sit on the baseline
- Pixelation, halos or paste rectangles around amounts and names
- Spelling or grammar errors on a bank, ATO, payroll or government document (these systems do not make typos)
- Inconsistent date formats within one document
- Layout that does not match the institution's real format (compare against any genuine document from the same institution elsewhere in the file - same employer, same bank)
- A "logo" that is low-res or subtly wrong

Two documents from the same source (two payslips from one employer) should be visually identical apart from the data. If they are not, say exactly what differs.

## 6. Per-document verdict

- `fail` - a high-severity authenticity finding stands against this document (arithmetic broken, tamper markers, wrong-person, credible visual fabrication)
- `review` - unresolved medium signals, or checks that could not run (image-only, no metadata, unreadable pages)
- `clean` - checks ran and passed

File-level roll-up is computed by the report: any doc `fail` or high authenticity flag → FAIL; any `review` or medium → REVIEW; else CLEAN.

## Recommended wording

Never "this document is fraudulent". Always the observation plus the verification path: "Request the payslip directly from the employer's payroll portal", "verify employment by phone using an independently sourced number", "ask the client for the original bank-issued PDF", "obtain the ATO income statement, which the client cannot alter". The broker owns the accusation decision; the report owns the evidence.
